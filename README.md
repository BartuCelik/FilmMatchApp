# 🎬 FilmMatchApp

Çiftler ve arkadaşlar için "Tinder" tarzı film eşleşme uygulaması.

## 🛠 Tech Stack
- **Framework:** React Native (Expo)
- **API:** TMDB (The Movie Database)
- **UI:** React Native Deck Swiper, Axios
- **Database:** Firebase (In Progress)

## 🚀 Hızlı Başlangıç
1. `npm install`
2. `.env` dosyasına `EXPO_PUBLIC_TMDB_API_KEY` ekle.
3. `npx expo start`
